📋 API Endpoints

GET /api/users Get all users ⌄

Returns all users. Supports optional query parameters for filtering.

?search=annick ?minAge=18 ?maxAge=30 
"success": true,
"count": 3,
"data": [
  {
    "id": 1,
    "name": "IYIZIRE Annick",
    "email": "iyizireanique16@gmail.com",
    "age": 20,
    "createdAt": "2026-09-15T10:00:00.000Z"
  }
]
GET /api/users/:id Get user by ID ⌄

Returns a single user. Returns 404 if not found.

"success": true,
"data": {
  "id": 1,
  "name": "IYIZIRE Annick",
  "email": "iyizireanique16@gmail.com",
  "age": 20
}
POST /api/users Create new user ⌄

Creates a new user. Validates name, email, and age. Returns 409 if email exists.

REQUEST BODY:

{
  "name": "IYIZIRE Annick",
  "email": "iyizireanique16@gmail.com",
  "age": 20
}

RESPONSE (201 Created):

"success": true,
"message": "User created successfully",
"data": { "id": 4, ... }
PUT /api/users/:id Update user (full) ⌄

Fully replaces a user's data. All fields required. Returns 404 if not found.

"success": true,
"message": "User updated successfully",
"data": { ... }
PATCH /api/users/:id Partial update ⌄

Updates only the provided fields. Other fields remain unchanged.

{ "age": 21 }  // Only update age
DELETE /api/users/:id Delete user ⌄

Permanently deletes a user. Returns 404 if not found.

"success": true,
"message": "User \"IYIZIRE Annick\" deleted successfully"
GET /api/stats Get user statistics ⌄ 
"totalUsers": 3,
"averageAge": 28,
"youngest": { "name": "IYIZIRE Annick", "age": 20 },
"oldest": { "name": "Alain Kajangwe", "age": 35 }

📮 How to Test with Postman

Follow these steps to test your running API with Postman.

1

Run the server

npm install && npm start
2

Open Postman — Create a new request

Set method to GET, URL to http://localhost:3000/api/users, click Send

3

Test POST — Create a user

Method: POST | URL: /api/users | Body: raw JSON with name, email, age

4

Test DELETE — Remove a user

Method: DELETE | URL: /api/users/1 | No body needed

5

Save your collection

Save all requests in a Postman Collection named "SaiKet Task 4 API"
